# Architecture Decision Records

Un archivo por decisión no trivial, numerado: `0001-titulo.md`. Plantilla:

```
# 0001 — Título

**Fecha:** YYYY-MM-DD · **Estado:** aceptada

## Contexto
Qué problema había y qué opciones se consideraron.

## Decisión
Qué se eligió y por qué (con números si los hay).

## Consecuencias
Qué queda más fácil, qué queda más difícil, qué habría que revisar si cambia X.
```

Pendiente de escribir cuando se resuelva: proveedor de LLM (con el resultado del bake-off).
